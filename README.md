# PyPlants WebUI

A simple dashboard for PyPlants powered by Streamlit. This app allows users to easily run plant disease models and inspect results.

## View it online

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://pyplants-webui.streamlit.app/)

## Installation

To locally run this application you need to install it.

```console
python -m pip install -r requirements.txt
```

You can locally lunch the application in this way:

```console
python -m streamlit run streamlit_app.py
```

Enjoy.
